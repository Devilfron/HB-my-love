# HB-my-love

# 🎉 Інтерактивна вітальна листівка (Happy Birthday my love)

Невеликий пет-проект — анімована веб-листівка до Дня народження, створена для практики роботи з DOM-деревом, CSS-анімаціями та JavaScript-подіями.

## 🔗 Переглянути наживо
Відкрити листівку у браузері можна за посиланням:  
👉 **[Перейти до привітання](https://devilfron.github.io/HB-my-love/)**

## 🛠 Використані технології
* **HTML5** — семантична структура сторінки.
* **CSS3** — стилізація, візуальні ефекти та плавні анімації.
* **JavaScript (Vanilla JS)** — інтерактивність та запуск сценарію привітання.

## 📂 Структура проекту
* `index.html` — головна сторінка листівки.
* `style.css` — таблиця стилів та налаштування анімацій.
* `script.js` — логіка взаємодії з користувачем.
